# ☕ Get Me A Coffee

> **🚀 The core version of this project is complete and the project is now in active development.**

**Get Me A Coffee** is a crowdfunding platform where creators can receive support from their fans through small contributions.

The core functionality of the platform has been completed, including authentication, creator profiles, dashboards, payment integration, and responsive design.

The project will continue to receive new features, improvements, optimizations, and updates in the future.

## 🚀 Current Status

The **core concepts and main functionality of the project are complete**.

The project is now in **active development**, with future updates focused on adding new features, improving the existing experience, fixing bugs, and optimizing performance.

## 📋 Features

- 🔐 User Authentication
- 👤 Creator Profiles
- ☕ Support Creators
- 💳 Razorpay Payment Integration
- 📊 Creator Dashboard
- 📜 Donation History
- 🖼️ Profile & Cover Images
- 🔄 Profile Updates
- 📱 Fully Responsive Design
- 🔔 Toast Notifications
- ❌ 404 Handling for Invalid Usernames

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Next.js Server Actions / API Routes
- **Database:** MongoDB
- **Authentication:** Auth.js (NextAuth)
- **Payments:** Razorpay
